# IP Address & Time Display Browser Extension

A simple browser extension that displays your current public IP address and local system time in ISO format.

## Features

- Shows current public IP address
- Displays local system time in ISO format
- Updates automatically
- Lightweight and simple interface

## Installation

1. Clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked" and select the extension directory

## Development

This extension is built using:
- Manifest V3
- Vanilla JavaScript
- HTML/CSS

## Structure

```
IPAddress-Time/
├── manifest.json    # Extension configuration
├── popup.html      # Main extension popup
├── popup.js        # JavaScript logic
├── styles.css      # Styling
└── icons/          # Extension icons
```
